# Life Line Ambulance Service website

Next.js 16 site for https://lifelineambulances.in.

- Developers: start with `README-DEVELOPER.md`, then `DEPLOYMENT.md`.
- Owner / non-technical: `README-CLIENT.md`.
- QA record: `FINAL-QA.md`. Content, routes, SEO, analytics and contact references: `handover/`. Approved brand files: `brand/`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm start
```
